## 🧩 About

**Elden Ring helpers** is a curated list of Elden Ring open-source tools:

- **Overlays** — on-screen helpers, layout notes, stat viewer, quick menu panel
- **Quality-of-Life Helpers** — map notes, loot tracker, HUD adjustments
- **Research Notes** — build layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Gameplay Helpers
- Quick Menu Panel — toggle a compact in-game menu
- Stat Viewer — read current attributes and build notes
- Map Notes — annotate The Lands Between for study
- Playback Notes — review single-player session routes

### 🎨 Catalog & Cosmetics
- Armor Catalog — browse sets, colors, and notes
- Weapon Notes — organize armaments by build
- HUD Tweaks — adjust visibility for study comfort

### 🏋️ Practice Layout
- Route Notes — segment study across regions
- Config Presets — save and switch helper layouts
- Boss Pattern Notes — review telegraphs in single-player
